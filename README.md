# IFEN

Institute for EEG Neurofeedback IFEN Training, development and research center

Marketing site built with Next.js (App Router), React, TypeScript, CSS Modules and framer-motion.

## Run locally

```bash
npm install
npm run dev      # http://localhost:3000
```

## Production

```bash
npm run build
npm start        # honours $PORT
```

Deployed on Railway from the `main` branch.
