# IFEN

Institute for EEG Neurofeedback IFEN Training, development and research center

Marketing site built with Next.js (App Router), React, TypeScript, CSS Modules and framer-motion.

## Run locally

```bash
npm install
npm run dev      # http://localhost:3000
```

## Production

```bash
npm run build
npm start        # honours $PORT
```

Deployed on Vercel (project `ifen`) from the CLI: previews from `phase-2`, production from `main` with `vercel deploy --prod`.
